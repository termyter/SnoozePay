## Ключевые решения

### 1. Экран сработавшего будильника = нативный iOS 26
- **Решение:** ТОЧНАЯ копия нативного будильника iOS 26 (AlarmKit)
- **Layout:** размытый фон (wallpaper blur), "БУДИЛЬНИК" лейбл сверху, время крупно (Light weight), название будильника, две кнопки side-by-side внизу
- **Кнопки:** `Выключить` (зелёный frosted glass) | `Отложить · 50₽` (оранжевый frosted glass)
- **Баланс = 0:** кнопка "Отложить" → серая, текст "Баланс пуст", неактивна
- **Прогрессивная шкала:** кнопка красная, сумма увеличена (100₽, 200₽, 400₽...)

### 2. Дизайн-система
- **Шрифт:** SF Pro (системный iOS) — НЕ Inter. В Figma использован Inter как замена, в коде — системный шрифт
- **Стиль:** нативный UIKit, системные компоненты где возможно
- **Тема:** тёмная (primary), светлая (secondary, в будущем)

### 3. Подход "Code-first"
- Figma используется как референс, не как source of truth для pixel-perfect
- iOS Dev опирается на SPEC.md + DESIGN_SUMMARY.md + скриншоты Figma
- После готовности iOS — скриншоты обратно в Figma для документации

## Компоненты

### Кнопки
- **Primary (зелёная):** "Выключить" — `#30D158`, radius 16px, white text
- **Warning (оранжевая):** "Отложить (50 ₽)" — `#FF9F0A`, radius 16px, white text
- **Destructive (красная):** "Отложить (200 ₽)" — `#FF453A`, radius 16px, white text
- **Disabled (серая):** "Баланс пуст" — `#48484A`, radius 16px, white text 30% opacity

### Toggle
- **ON:** фон `#30D158`, белый кружок справа
- **OFF:** фон `#8E8E93` 40% opacity, белый кружок слева

### Settings Row
- Высота: 48px, фон `#2C2C2E`, radius 12px
- С chevron `›` — навигация
- С toggle — переключатель

### Tab Bar
- 3 вкладки: Будильники | Статистика | Настройки
- Монохромные SF Symbols, активная = `#0A84FF`, неактивная = `#8E8E93`
- Фон: `#1C1C1E`

## Инструкции для iOS Developer

1. **Источники правды (приоритет):**
   - `docs/SPEC.md` — полное ТЗ
   - `docs/DESIGN_SUMMARY.md` — этот файл (токены, решения)
   - `docs/DESIGN_TASKS.md` — детальные спеки незавершённых экранов
   - Figma (node 1:43, 1:150, 1:360 и т.д.) — визуальный референс

2. **Экран сработавшего будильника:**
   - ТОЧНАЯ копия нативного будильника iOS 26
   - Использовать AlarmKit (iOS 26+), UNUserNotificationCenter (iOS 18-25)
   - Единственное отличие: кнопка "Отложить" показывает цену
   - Баланс=0: кнопка серая "Баланс пуст"

3. **Стиль:**
   - Системный SF Pro шрифт
   - Нативные UIKit компоненты
   - UIColor из системной палитры где возможно
   - Никаких кастомных кнопок если есть системные аналоги
