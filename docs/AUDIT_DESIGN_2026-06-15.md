# Design audit — SnoozePay vs HTML-прототип (2026-06-15)

Посоэкранная сверка приложения с дизайн-прототипом ветки `design-refresh-2026-04-27`.
Прогон скилла `/audit design` (issue #339; харнесс — #338).

## Методология

- **Эталон:** HTML/CSS-прототип `docs/design/snoozepay-2026-04-27/project/` (`All Screens.html`,
  `tokens.css`, `components/SP*.jsx`) — **НЕ** устаревшие V2-Figma-ноды.
- **Снято:** 20 экранов через `UITourLauncher` (`-uitour <screen> -uitour-seed`), iPhone 17 Pro Max iOS 26.5.
  Эталоны — element-clip артбордов `[data-dc-slot] .phone` (393×852) через headless Chrome + CDP.
- **Сверялись:** структура/layout, отступы (`tokens.css` 4px-base), цвета (hex), типограф-иерархия, копирайт.
- **Не считались дельтами:** шрифт (SF Pro в коде vs Manrope/JetBrains Mono в прототипе), живые данные
  (время/баланс/countdown/дата/стрик), ±1-2pt.

### ⚠️ Важно про тему (light vs dark)

Первый прогон случайно шёл при **светлой** теме симулятора (`simctl ui appearance light`), из-за чего
почти каждый экран показал ложную дельту «app light vs design dark». Это **артефакт съёмки, не баг:**
`tokens.css` содержит полноценную палитру `[data-theme="light"]`, т.е. приложение **легитимно
поддерживает обе темы**, а канвас прототипа просто отрисован в dark. Перепрогон выполнен в **dark**
(`simctl ui appearance dark`) для apples-to-apples. **Тема исключена из находок.** Вывод на будущее
(зашит в SKILL.md): аудит дизайна гнать в dark, темо-расхождения — не находка.

## Заведённые / связанные issues

**Новые (этот прогон, `status:proposed audit-finding`):**
- **#346** — sound-picker: нет инлайн-плеера превью (p2)
- **#347** — streak: нет суммы сэкономленного + share-кнопки (p2)
- **#348** — stats: нет блоков «Время подъёма» + денежного итога (p2, medium conf.)
- **#349** — alarms: нет пилюли множителя ×N (p3)
- **#350** — create/edit: слайдер снуза без карточки/границ (p3)
- **#351** — edit: «Готово»→«Сохранить», «✕»→«Отмена» (p3)

**Уже отслеживалось (дедуп, не плодил):**
- #342 firing — пилюля баланса не меняет цвет
- #343 alarms — ведущий ноль во времени (косметика)
- #344 create — плейсхолдер без «напр. Будни»
- #345 firing-nobalance — перекрытие текста (баг)
- #341 alarms — «дни недели сдвинуты» — **закрыто/неверно:** при чистом seed РАБОТА корректно
  показывает ПН-ПТ; прошлый прогон ловил stale-данные (не чистил seed). Подтверждаю отсутствие бага.

**Намеренные расхождения / зона PM (не заводил):**
- Профиль-карточка settings, способы оплаты, Apple Pay-брендинг, второй volume-тоггл (Critical Alerts) —
  billing / entitlement / no-touch.
- txhistory «Пополнения», deposit IAP-тиеры, RU-список звуков, gear в alarms — намеренные продуктовые решения.

## Косметика (перечислено, issues НЕ заводил)

permissions icon-tiles (серые vs зелёные для granted), theme-picker чек-стиль, txhistory иконки строк,
streak day-chips (круги vs скруглённые квадраты), slider thumb (зелёный vs синий в эталоне), ведущий ноль
во времени (#343).

## Оговорки

SF Pro vs Manrope + живые данные → сверялись структура/отступы/цвета/иерархия, не пиксели. `firing*` —
нативный iOS 26, прототип лишь референс (дельты информационные). `confirm-delete` требует доработки таймингов
харнесса для чистого снимка.
